使用說明

這裡整理配送部系統目前所有功能的操作方式。系統每次上線新功能或調整既有功能， 這頁都會同步更新，不用擔心看到過時的說明。

系統總覽 從應徵到報到（完整流程） 登入與權限 人員管理 合作方式管理 應徵名單 補款／假別登記 車輛管理 意外事件回報 裝備借還管理 外送員接單媒合 報班媒合 每日加退保 查詢人員／批次匯入

系統總覽

登入後從主頁（/delivery/）點選任一模組即可開始使用，各模組彼此獨立、互不影響。

  • 人員管理：選擇廠商查看配送人員缺件狀況
  • 應徵名單：Google 表單自動匯入，錄取自動建立人員
  • 補款／假別：登記、主管核准、可匯出 Excel
  • 車輛管理：LINE 群組回報領還車，自動寫入記錄
  • 意外事件：LINE 群組回報自動建案，可設風險等級
  • 裝備借還：籃子、橘衣等裝備借用歸還轉倉買斷
  • 外送員接單媒合：已登記合作的承攬騎士在 LINE 私訊自助承接附近門市
  • 報班媒合：已登記合作的雇傭騎士在 LINE 私訊報名附近的報班時段，管理員人工審核
  • 每日加退保：本部門（新北所(配送組)）每天上傳加退保 Excel 給人資彙整
  • 查詢人員：依姓名或身分證字號快速查詢

從應徵到報到（完整流程）

一位新人從填應徵表單，到正式報到上工，在系統裡依序會經過下面六個步驟。各功能更細的說明，見下方「應徵名單」「人員管理」等段落。

① 應徵者填 Google 表單 → ② 應徵名單面試、記錄 →（UD、UC、三輪雇傭要先試駕通過）→ ③ 按「錄取」自動建立人員（待報到）→ ④ 人員詳細頁補資料、上傳文件 → ⑤ 改成「在職」完成報到 → ⑥ 報到後的相關作業

① 應徵者填寫 Google 表單

  • 應徵者填完各廠商的應徵表單，資料會自動出現在「應徵名單」，不用手動輸入
  • 依填的是哪一份表單，自動帶入廠商（例如蝦皮三輪、UD），有些表單也會帶入合作方式
  • 同一個人重複填表（姓名＋電話都一樣）：用新的回覆蓋掉舊的，不會多一筆；處理狀態會重設回「未面試」，但之前記錄的試駕結果跟備註會保留

② 應徵名單：面試與記錄

入口：主頁 →「應徵名單」。

  • 處理狀態：未面試 → 已面試；應徵者不來了就選「放棄」
  • 廠商／合作方式：系統自動帶入，帶錯可以直接改
  • 試駕：未試駕／通過／未通過
  • 備註：自由填寫，例如面試印象、約定的報到時間
  • 其他回覆：應徵者在表單填的內容（可配合天數、熟悉的行政區等），面試時參考用
  • 改完一次按更新按鈕，可以同時更新好幾個人；「已錄取」「放棄」的人預設不顯示，用姓名搜尋或篩選狀態才會出現

③ 錄取並建立人員

在該應徵者那一列按「錄取」。

  • 要先選好廠商，沒選會被擋下來
  • 要先試駕通過才能錄取：廠商是 UD 或 UC，或合作方式是 三輪雇傭（不論哪個廠商）。試駕沒改成「通過」就按錄取會被擋下來，剛才選的廠商、打的備註都會保留，不用重填
  • 錄取成功後，系統自動建立正式人員資料，人員狀態是「待報到」；只會帶入姓名、電話、廠商、合作方式，其他資料要在下一步補

④ 人員詳細頁：補資料、上傳報到文件

入口：主頁點該廠商（例如「UD」）→ 人員清單 → 點姓名，或用「查詢人員」搜尋姓名。新錄取的人一定還缺文件，所以預設就會出現在該廠商的人員清單裡。

  • 頁面上方：合作方式、負責客戶（UD 才有）、到職日期、工號（要用 LINE 接單／報班的人才需要）
  • 合作方式要先選對：下方要交哪些文件，是依「廠商＋合作方式」自動決定的，選錯就會列錯
  • 應備項目，每一項會標「缺件」或「已備齊」：
    • 直接填寫：身分證字號、Email（UD／UC）——系統會檢查格式
    • 勾選「有」：駕照、合約簽定、UBER 系統（UD／UC）、MOMO 測驗（UD 負責 MOMO 的人）
    • 上傳照片：自拍照（UD）、拍照（UC）
    • 上傳並記錄到期日：良民證（蝦皮系列以外）、強制險、營業用第三責任險、公會加保證明——上傳後系統會自動辨識到期日，辨識不到就手動填；快到期時系統會用 LINE 提醒
  • 全部填好按「一鍵全部更新」一次送出；檔案可以是 JPG、PNG、HEIC、PDF，單一檔案最大 10MB

⑤ 改成「在職」＝完成報到

  • 同一頁上方的「人員狀態」從「待報到」改成「在職」，按「一鍵全部更新」
  • 報到前才說不來了，改成「放棄報到」（之後預設不出現在清單，用姓名搜尋還找得到）
  • 「在職」要自己改：文件全部備齊後，系統不會自動改成在職；反過來，文件還沒齊系統也不會擋你改成在職。請先確認應備項目都是「已備齊」再改
  • 到職日期也要記得填：改成在職時系統不會自動帶入日期，但特休天數是依到職日期計算的

⑥ 報到後的相關作業

  • 每日加退保：當天有人報到，要在主頁「每日加退保」上傳加保 Excel 給人資（見下方「每日加退保」）
  • LINE 接單／報班：要讓騎士用 LINE 自己接單（承攬）或報班（雇傭），要先在人員詳細頁填好工號，騎士再到 LINE 私訊「綁定＋工號＋姓名」（見下方「外送員接單媒合」「報班媒合」）
  • 裝備借用：籃子、橘衣等裝備只能借給狀態是「在職」的人，所以要先完成第 ⑤ 步

登入與角色權限

  • 使用材霈平台帳號密碼登入，跟職缺維護等其他系統共用同一組帳號
  • 登入失敗次數過多，帳號會暫時鎖定，稍後再試或聯絡管理員
  • 帳密正確但沒有配送部系統權限時，會看到提示訊息，請找管理員開通
  • 一般同仁：可以日常登記（補款、假別、裝備借還）、查詢、篩選、新增人員／車輛等資料
  • 主管（管理員）：多了核准補款／假別、結案意外事件、刪除紀錄、維護合作方式／服務區域等清單的權限

人員管理

主頁點選廠商（UD、UC、蝦皮、順豐…）進入該廠商的人員清單。

  • 預設只顯示「有缺件」且狀態不是離職／放棄報到的人員，畫面不會被無關紀錄塞滿
  • 可用姓名、電話、在職狀態、缺件狀態篩選；主動搜尋姓名時，連離職的人也查得到
  • 主管可以在清單刪除人員紀錄（不可逆，會一併刪除上傳過的所有檔案）
  • 人員詳細頁是一頁式大表單：合作方式、負責客戶、身分證字號、Email、勾選類／上傳類文件，一次送出、一鍵更新
  • 應備文件會依「廠商 + 合作方式」自動決定，例如強制險、公會加保證明、良民證等
  • 上傳保險文件時，系統會自動辨識到期日（OCR）；辨識不到再手動補上即可
  • 人員狀態改成「離職」時，如果名下還有裝備借用未歸還，畫面會跳出提醒視窗（提醒用，不會擋著不給存檔）

合作方式管理

  • 合作方式（二輪承攬／二輪雇傭／三輪雇傭…）可以自行維護，不用再找工程師改程式
  • 開放「全部廠商」使用，不再只有蝦皮系列才看得到這個欄位
  • 新增／編輯一筆合作方式時，可以勾選「適用哪些廠商」——蝦皮與蝦皮三輪速配倉可以繼續共用同一組
  • 入口：人員清單或應徵名單頁首的「合作方式管理」按鈕（主管專用）

應徵名單

流程：Google 表單送出 → 自動出現在名單 → 標記已面試／放棄 → （UD、UC 或合作方式為「三輪雇傭」需先通過試駕）→ 錄取並建立正式人員。

  • 廠商、合作方式會依表單來源自動帶入，同仁可以自己修改
  • 「已錄取」「放棄」的人預設不顯示，主動搜尋姓名或篩選狀態才會列出來
  • 錄取送出後自動建立正式人員資料，之後再到人員詳細頁補身分證字號、上傳報到文件即可

補款登記／假別登記

  • 補款登記：填寫送出 → 記錄頁可搜尋 → 主管核准 → 可匯出 Excel；已核准的紀錄不能刪除，避免帳務對不起來
  • 假別登記：填寫送出 → 額度達 90% 系統會自動提醒 → 主管核准 → 可匯出 Excel

車輛管理

  • 同仁在指定的 LINE 群組回報領車／還車，格式化訊息會自動解析並寫入系統
  • 系統會擋下不合理的操作，例如「車輛已在使用中，卻又被回報領車」
  • 網頁上也可以「手動補登」一筆領還紀錄，送出後同步推播通知到 LINE 群組
  • 「一鍵整理車輛狀況」可以產生文字報告，直接複製貼到群組
  • 服務區域（台北、新北、桃園…）可自行新增／停用，公司拓點到新縣市不用再找工程師——入口在車輛管理頁首「服務區域管理」（主管專用）
  • 車輛清單手機號碼旁邊會顯示這台車目前使用人的合作方式（騎手身份），篩選列也有對應的下拉選單；系統依姓名＋電話自動比對使用人資料，沒顯示代表比對不到人、或對方合作方式還沒填
  • 站所（2026-09-22 新增）：自由文字欄位，不分廠商，全部車輛都能填，車輛詳細頁可以直接更新
  • UD 廠商自動同步到材霈試算表（2026-09-22 新增）：廠商是 UD 的車輛，每次領車/還車（不管是 LINE 群組回報還是網頁手動補登）都會自動在材霈自己維護的「三輪車」試算表新增一列紀錄，同步失敗不會擋住領車/還車本身——如果發現試算表沒更新，先確認試算表有沒有分享「編輯者」權限給 Cloud Run 服務帳戶

意外事件回報

  • 同仁在指定的 LINE 群組回報意外事件，系統會自動建立事件紀錄
  • 主管可以在詳細頁設定風險等級、標記結案
  • 主頁會提示目前有幾筆「未結案」的意外事件，避免遺漏後續處理

裝備借還管理

  • 籃子、橘衣等裝備的借用／歸還／轉倉／採購／買斷，直接在網頁填表單即可，不用照 LINE 回報格式
  • 裝備品項、放置點都是可自行新增／停用的清單，主管在管理頁面上自行維護
  • 退保連動提醒：人員改成「離職」時，如果名下還有裝備沒還，畫面會跳出提醒視窗（提醒用，不會擋著不給存檔）

外送員接單媒合（即時接單）

跟現有排班「發包」機制（專員主動推播調度表、騎士被動接受）是相反方向的操作——這個功能是騎士自己在 LINE 私訊主動查詢、自助操作，不會用到發包機制的任何資料。只有已登記在案的合作騎士（在 LINE 私訊過「綁定+工號+姓名」）才能使用，管理員可以在後台個別停用不合規的騎士。報班媒合的說明見下一節。

  • 即時接單僅限承攬身份：資格是即時查這位騎士在人員名冊裡目前的合作方式決定（不是綁定當下寫死），要先在人員名冊補上工號、在合作方式管理設定好承攬/雇傭分類，這位騎士才能用——查不到工號對應的人員資料，或合作方式還沒設定分類，都不能用
  • 騎士端流程：私訊「查詢附近單」→ 點一下對話框上方跳出的「分享目前位置」按鈕（一次性，不會持續追蹤）→ 系統列出附近開放中、還缺騎士、而且在這間門市服務半徑內的門市 → 點「承接」就直接完成，系統回覆「已登記承攬請前往配送」，不用再回覆件數
  • 管控依據是「需求騎士數量」，不是件數（2026-09-22 改版）：門市當日量的「件數」只是顯示給騎士參考這間門市大概有多少貨，真正決定還能不能接的是「需求騎士數量」——一位騎士佔一個名額，接滿了這間門市就不會再出現在其他騎士的清單上
  • 同一位騎士不能重複承接同一間門市：已經接過的門市不會再出現在他自己的清單裡，就算硬點舊卡片也會被擋下
  • 承接成功會自動通知配送組作業群組（2026-09-22 新增）：跟領車/還車通知同一個群組，內容包含騎士姓名、門市、承接時間、這間門市還缺幾位騎士
  • 服務半徑（配送部/管理部同仁）：開門市當日量時可以調整「幾公里內的騎士才看得到」，預設 10 公里，每一筆可以不一樣；騎士分享位置後，系統只會列出還在範圍內的門市
  • 即時接單地點管理（配送部/管理部同仁）：先把常用門市連同經緯度登記一次，之後開當日量就能直接從清單搜尋選用，不用每次手動查經緯度；地點可以停用但不會刪除，不影響舊紀錄。這份清單跟報班地點清單完全獨立、互不共用
  • 門市當日量管理（配送部/管理部同仁）：從地點清單選門市、填當日量（件）、需求騎士數量跟服務半徑，兩個數字之後都可以隨時調整，也可以直接關閉這筆；每筆都能查看目前有哪些騎士承接、什麼時候接的，方便對帳
  • 騎士名單管理（限管理員）：查看所有已綁定的騎士，附上即時算出的合作身份（承攬/雇傭/未對應）；工號/姓名打錯字可以直接在這裡編輯後按「儲存」，效果跟騎士自己重新私訊綁定一次完全一樣；停用後這位騎士的接單/報班功能會立即被擋下，是疊在合作身份判斷之上的手動覆蓋。目前這份名單同時涵蓋即時接單跟報班媒合兩邊的騎士
  • 目前是試營運階段：門市當日量由後台人工登記，還沒接回試算表自動同步，承接後也不需要另外「回報送達」——之後接回試算表時會另外通知

報班媒合

跟即時接單同一個 LINE 官方帳號、同一份騎士名單，但適用對象跟流程都不一樣：即時接單給承攬騎士、當下就成立；報班媒合給雇傭騎士、要管理員人工審核才算數。

  • 報班媒合僅限雇傭身份：判斷方式跟即時接單一樣，是即時查人員名冊裡目前的合作方式分類
  • 騎士端流程：私訊「瀏覽報班」→ 點一下分享位置按鈕 → 系統列出附近開放中、在這個時段服務半徑內的需求時段 → 點「報名」→ 系統回覆「已收到報名，需等管理人員確認後才算成功」
  • 名額是人工審核制：報名不會由系統自動比對名額決定成不成功，一律先存成「待審核」，管理員在「報班時段管理」→「查看名單」手動按「核准」（報名成功）或「駁回（額滿）」，額滿與否由管理員自行判斷，系統不會自動擋下超過需求人數的核准
  • 審核結果要騎士自己查：核准/駁回不會主動推播 LINE 訊息，騎士要自己私訊「查詢報名狀態」查最近幾筆的結果（核准＝報名成功，駁回＝額滿，請改報其他時段）
  • 報班地點管理（配送部/管理部同仁）：報班自己獨立的一份地點清單，跟即時接單那份完全不共用；先登記地點跟經緯度，開時段時就能直接搜尋選用
  • 報班時段管理（配送部/管理部同仁）：從報班地點清單選地點、填時間、需求人數跟服務半徑，可查看報名名單、隨時關閉；也可以用 Excel 批次匯入（地點名稱要跟報班地點清單完全一樣）一次建立多筆時段，請下載頁面上的 Excel 範本填寫再上傳（舊的 CSV 檔案也還收得進來）；清單可以依地點／日期篩選
  • 服務半徑：每個時段各自設定「幾公里內的騎士才看得到」，預設 10 公里

每日加退保

主頁的「每日加退保」按鈕只有部門是「新北所(配送組)」的帳號才看得到——這是跟人資彙整每天加退保 Excel 的功能，不用另外勾任何模組權限，帳號部門對了就能用。

  • 上傳：選日期，上傳當天的加退保 Excel（跟原本傳給人資的格式一樣）；同一天再傳一次會直接蓋掉前一份，不是累加
  • 查歷史：只能查自己部門的歷史上傳紀錄
  • 人資收單後，當天就不能再上傳，需要補傳請聯絡人資
  • 完整的加退保功能說明（給人資彙整/收單/下載用）見「人資專區」的使用說明頁

查詢人員／批次匯入

  • 主頁輸入姓名或身分證字號，即可快速查詢缺件狀況，不用先知道這個人屬於哪個廠商
  • 大量新人時，可以用 Excel 一次匯入，不用一筆一筆手動新增。請下載頁面上的 Excel 範本填寫再上傳——自己另存成 CSV 的話，「堃」「喆」這類 Big5 放不下的姓名用字會被 Excel 換成問號，而且電話開頭的 0 會不見（舊的 CSV 檔案還是收得進來，只是有這兩個風險）
  • 系統會自動抓重複：同姓名＋電話已有在職人員時會自動跳過

操作上有疑問，或發現系統跟實際狀況對不起來，請聯絡系統管理窗口。
